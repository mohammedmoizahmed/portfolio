EC2 Portfolio Deployment (AWS Cloud Project)

I deployed my personal portfolio website on an AWS EC2 instance using Amazon Linux 2023 and the Apache (httpd) web server. This project demonstrates my ability to configure cloud servers, manage networking, and host production-ready web applications. (The instance is not active currently as I am running the free tier, But it can be started anytime for proof).

Key Tasks Performed

  • Launched EC2 (Amazon Linux 2023) instance
  • Installed & configured Apache (httpd) web server
  • Uploaded HTML/CSS portfolio
  • Configured security groups (HTTP/SSH)
  • Tested desktop + mobile responsiveness

Tools Used

AWS EC2 Amazon Linux 2023 Apache (httpd) SSH Security Groups HTML/CSS
